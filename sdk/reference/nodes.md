# REDGraph node reference - Cyberpunk 2077 2.31

Generated by `scripts/sdk_node_reference.py` from 124 census windows of REDGraph's `[Diagnostics] RenderGraphDump` (raster, RT and PT gameplay, menus, loading). Every row is something the census SAW bind / dispatch inside that node - a node can bind more in scenes we did not visit. The full table, with full hashes, is `node_shaders.csv`.

* **node** = the name for `node_wrap`, `node_remove`, `node_register(after=...)`, `patch_scope`, `companion_scope`, `rt_variant(node=...)`. A **group** name works for `node_wrap` and the scopes too.
* `[job]` = the work runs in a job the node submits (it still counts as the node's).
* **modes** = the render modes it ran in (raster / RT / PT); `?` = seen only in early runs that did not record the mode.
* Engine shaders are listed by hash prefix and engine name; material shaders (the world's geometry) are only counted.

Rows are in FRAME ORDER (the order of every census graph, merged); nodes seen only in the small menu / loading graphs come last.
