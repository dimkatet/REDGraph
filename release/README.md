# Nexus page

`nexus-page.bbcode` is the page itself (Description field, BBCode). Edit it with the release that changes what it says.

## Short description (Nexus field limit: 255 characters)

Render host for Cyberpunk 2077 that other mods build on. Does nothing on its own - install it when a mod needs it. Open source, with an SDK for modders.

## Files tab

- `REDGraph-<version>.zip` - main file (the plugin + its CET window).
- `REDGraph-SDK-<version>.zip` - optional file, for modders.

Both come from the GitHub release of the same tag (or `scripts/package_mod.ps1` / `scripts/package_sdk.ps1`).
